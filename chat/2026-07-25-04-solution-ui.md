## Recommendation: **Tad** + **DBeaver**

### Tad (for quick file browsing)

Opens your parquet/CSV files directly, no import, no database:

```bash
# Install (AppImage, no deps needed)
wget https://github.com/antonycourtney/tad/releases/download/v0.14.0/Tad-x86_64.AppImage
chmod +x Tad-x86_64.AppImage
./Tad-x86_64.AppImage data/episodes/episode_vehicles.parquet
```

Features: sort any column, filter by value, histogram per column, handles millions of rows with virtual scrolling.
